## Historical source assessment, 2026-10-13

**Allowed, with conditions, according to Obsidian's own documentation.** The Terms of Service have
no clause about automation, servers or bots. The documentation names this use:

- Headless Sync (https://obsidian.md/help/sync/headless): "Useful for CI pipelines, agents, and
  automated workflows. Sync the latest changes or keep files continuously up to date."
- Obsidian Headless (https://obsidian.md/help/headless): "Give agentic tools access to a vault
  without access to your full computer." and "Run scheduled automations".
- Sync (https://obsidian.md/sync): "even headless on a server".

Conditions from the Terms (https://obsidian.md/terms, updated 2025-02-20) and staff statements:

- Personal use only. Restriction (i) forbids making the Services or Software "available for access
  by third parties", and restriction (v) forbids using them "to provide a service for others".
- Do not redistribute, modify or decompile the client (restrictions (i) to (iii)). We install it
  from npm on the host and never bake it into a published image.
- Keep the login confidential.
- Back off on errors and log in once. Licat (https://forum.obsidian.md/t/102387/5): "make sure your
  scripts have appropriate error handling and back-off mechanisms so you don't DoS our servers on a
  loop." lishid (https://github.com/obsidianmd/obsidian-headless/issues/36): "log in once and reuse
  the same session token."

Licences:

- No commercial licence is needed (https://obsidian.md/license: "Obsidian is free for all purposes,
  including personal, commercial, and non-profit use"). A Sync subscription is needed.
- The client is `UNLICENSED`. The maintainer wrote in
  https://github.com/obsidianmd/obsidian-headless/issues/39: "You should be ok to use it or
  integrate with it following the rules from https://obsidian.md/license and
  https://obsidian.md/terms". Redistribution (issue #52) has no answer.
- The client is in open beta. Staff: "Expect more breaking changes in this beta period."
  (https://forum.obsidian.md/t/111740/5). Open data-loss issues exist (#19, #28), so the read path
  runs `pull-only` first and the vault is backed up.

## Sync limits that matter for a server device

| Limit | Standard | Plus |
|---|---|---|
| Synced vaults | 1 | 10 |
| Maximum file size | 5 MB | 200 MB |
| Account storage, version history and attachments included | 1 GB | 10 to 100 GB |
| Note version history | 1 month | 12 months |
| Attachment version history | 2 weeks | 2 weeks |
| Devices | unlimited | unlimited |

Source: https://obsidian.md/help/sync/plans and https://obsidian.md/help/sync/faq. When storage is
full, Sync stops syncing files. Frequent automated writes make more versions, and versions count
toward storage. No numeric rate limit, fair-use rule or transfer limit is published.
