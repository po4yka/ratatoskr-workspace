Deployment

The host is frozen as of 2026-08-21. Nothing is deployed to it or changed on it. Only Platform's three units were ever installed, on 2026-08-19 (milestone 10), and that slice ran end to end. The rest of this view is the target every service must fit, read from the deploy files and config defaults in each repository.

One Raspberry Pi 5 (4 × Cortex-A76, 15 GiB RAM, aarch64, 16 KiB pages, Debian 12 class). Ratatoskr binaries run as systemd units, one per role; PostgreSQL, NATS, cloudflared and the metrics stack are containers.

Backups

Not backed up: JetStream, and the Vault and AI archive blobs. The SATA copy is in the same machine, so the 04:00 S3 copy is the only off-host one.

Open gaps

  1. Edge routes /v1/vault, /v1/social and /v1/ai to ports 8093 to 8095, and no service binds them yet. Edge reports those capabilities stale on purpose.
  2. No repository serves the web client's built bundle. Platform has no static route, and the port table allocates no port for it.
  3. The bus alert rules exist in platform/deploy/monitoring/, but no alert engine loads them.
  4. The metrics stack does not set extra_hosts: host-gateway, and node-exporter collects no disk or filesystem series. Both are host state on a frozen host.

Public API

Platform owns the public HTTP surface and generates its OpenAPI 3.1 document from its own routes; contracts owns the types the routes carry (platform ADR-0006). Web generates its client with openapi-typescript 7.13.0 and mobile with openapi-generator 7.25.0, each pinned by a lock file.

Profiles & build order

Which repositories each manifest profile groups, and the order a cross-repository change has to move in. The profiles are declared in workspace.toml; the Compose files that will start them are planned, and the one integration profile running today is web-operational. A repository's manifest dependencies all sit in earlier layers, so a layer can be built and verified once the layers to its left are green. Contract changes still follow expand, migrate, contract.
